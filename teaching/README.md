# Teaching pack — "RAG beyond the demo: grounded, gated and guard-railed"

A 90-minute, post-graduate session taught **on the real D6T1 repository** as the
case study. Duration and mapping assume the trainee has the repo buildable.

- `slides.md` — 20-slide deck for the session.
- `lab.md` — hands-on lab against this repo, with expected outputs, stretch challenges and an answer key.
- `assessment-map.md` — learning outcomes mapped to the assessment items.
- `common-mistakes.md` — the five misconceptions the session actively corrects.

Prerequisites: .NET 10 SDK, Docker (optional), a clone of this repository.
